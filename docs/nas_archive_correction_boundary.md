# NAS归档更正的安全边界

仅当同步任务状态为pending或blocked、attempts严格为0，且不存在synced_at、lease_token、lease_until、last_heartbeat_at时，允许现有归档更正事务继续。旧target_path本身不代表已发送，因此允许未领取任务重新定位。

更正保持原版本比较、历史权限、资源权限、编辑令牌、本地附件SHA256校验及事务边界。成功时把任务归属改为新记录，将状态设为blocked，清空旧target_path、target_name和调度时间，要求管理员核对目标目录后重试；原记录目录映射属于其他附件可能复用的资源，不删除。保留原上传人和账号快照，避免跳过后续账号变更确认。原同步任务纳入更正前审计信息。

有任何已领取/尝试/同步迹象则409拒绝，包含租约过期后又回到pending的任务。不能通过清零attempts、清空租约或删除同步记录来绕过保护。

已同步附件迁移仍未实现。下一阶段需要真实NAS worker联调：设计独立、持久、可恢复的迁移任务，绑定旧路径/新路径/附件SHA256与操作者审核；冻结读写冲突，校验远端原件，按不可覆盖方式复制并校验目的文件后确认平台位置，明确旧副本保留/删除策略与授权，记录审计；必须覆盖提交结果丢失、网络中断、重复领取、目的路径冲突与回滚。当前不能声称已支持同步后更正或远端搬移。
